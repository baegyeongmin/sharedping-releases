F10

입장 코드

F9

핑 종류

찍은 사람 닉네임과 색이 같이 뜨고, 종류마다 소리가 다르다. 휠 네 칸의 이름·아이콘·색·소리는 방마다 관리자가 바꿔둘 수 있다.

  • ⬇︎갑니다Alt + 오른쪽
  • ⚑도와주세요Alt + 아래
  • ?적 사라짐Alt + 왼쪽
  • ·일반핑Alt + 클릭
  • T댓글Alt + T

자주 묻는 것

화면 공유하는 사람도 깔아야 하나?

아니다. 보는 사람끼리 쓰는 앱이다. 공유하는 사람도 깔면 친구들 핑이 자기 화면에도 뜬다.

게임하면서 써도 되나?

평소 클릭은 전부 아래 창으로 지나간다. 게임에서 Alt를 써야 하면 F8로 내 핑 입력만 잠그면 된다. 다만 전체화면 게임 위에는 안 뜬다. 게임 화면 모드를 '테두리 없음'으로 바꿔야 보인다.

친구랑 화면 크기가 달라도 같은 자리에 뜨나?

뜬다. 핑 위치는 공유 화면 안의 비율로 보내서, 모니터나 디스코드 창 크기가 달라도 같은 곳에 뜬다.

내 화면이 다른 사람한테 전송되나?

안 된다. 서버로 가는 건 핑 종류, 화면 안 위치, 닉네임, 댓글 글자 정도고 같은 방 사람에게만 전달된다.

설치할 때 경고가 뜨는데?

코드 서명 인증서가 없어서 윈도우가 '알 수 없는 게시자'로 표시한다. '추가 정보 → 실행'을 누르면 설치된다. 설치한 뒤 업데이트는 알아서 받는다.
